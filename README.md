# SkillSwap AI

Plataforma web para la recomendación de mentores y el intercambio
de habilidades entre estudiantes de TECSUP.


La integración local de `develop` se inicia siguiendo la [guía de sustentación y pruebas manuales](docs/INTEGRACION-Y-PRUEBAS-MANUALES.md). No ejecutar migraciones ni seeds para arrancar la demo existente.
