# SkillSwap AI

Plataforma web para la recomendación de mentores y el intercambio
de habilidades entre estudiantes de TECSUP.

## Tecnologías del backend

- Node.js
- Express.js
- MySQL Server 8.4 LTS
- MySQL Workbench

## Desarrollo local

- API Express: http://localhost:4000
- Base de datos MySQL: 127.0.0.1:3306
- Esquema: skillswap_ai

## Organización

- backend/src: código de aplicación
- backend/database: scripts SQL y migraciones
- backend/tests: pruebas
